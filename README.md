# SFP
## Simulation of physical processes (Симуляция физических процессов)
### Данная программа рассчитывает некоторые физические величины в некоторый промежуток времени(вводимый пользователем) с временным шагом(также вводимый пользователем) в конкретных физических явлениях и процессах.
**На данный момент в программе доступно:**
1. *Падение тела с сопротивление воздуха*
    (данные на выходе -
     * Сила сопротивления(F)
     * Скорость падения(v)
     * Ускорение падания(a)
     * Пройденный путь за секунду(S)
     * Координата тела(x)
     * Время симуляции(t))
3. *Колебания пружины*
    (данные на выходе -
     * Координата пружины(x)
     * Скорость(v)
     * Ускорение(a)
     * Время симуляции(t))
5. *Движение с постоянным ускорение*
    (данные на выходе -
     * Координата тела(x)
     * Скорость(v)
     * Пройденное расстояние(S)
     * Время симуляции(t))
7. *Баллистическое движение* (бросок тела под углом)
   (данные на выходе -
   * Координаты(x, y)
   * Скорость
   * Время симуляции(t))

Для запуска приложения:
1. *Windows* - Скачать файл SFP.exe и запустить(возможно необходимо будет отключить антивирус)
2. *Linux* - Скачать файл SFP, перейти в директорию с файлом и выполнить команду ```./SFP```
