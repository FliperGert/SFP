# SFP
## Simulation of physical processes (Симуляция физических процессов)
### Данная программа рассчитывает некоторые физические величины в некоторый промежуток времени(вводимый пользователем) с временным шагом(также вводимый пользователем) в конкретных физических явлениях и процессах.
**На данный момент в программе доступно:**
1.* *Падение тела с сопротивление воздуха* * (данные на выходе - Сила сопротивления(F), Скорость падения(v), Ускорение падания(a), Пройденный путь за секунду(S), Координата тела(x), Время симуляции(t))
2.* *Колебания пружины* * (данные на выходе - координата пружины(x), скорость(v), ускорение(a) и время симуляции(t))
3.* *Движение с постоянным ускорение* *(данные на выходе - координата тела(x), скорость(v), пройденное расстояние(S) и время симуляции(t))
4.* *Баллистическое движение* *(бросок тела под углом)(данные на выходе - координаты(x, y), скорость и время симуляции(t))
